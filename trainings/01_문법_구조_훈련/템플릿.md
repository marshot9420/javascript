# 예시

| 코드                | 전체 단위        | 내부 단위               | 평가 결과                        |
| ------------------- | ---------------- | ----------------------- | -------------------------------- |
| `10`                | 표현식           | 숫자 리터럴             | 숫자 값 `10`                     |
| `10;`               | 표현식 문        | 숫자 리터럴 표현식      | 숫자 값 `10`                     |
| `1 + 2`             | 표현식           | 덧셈 표현식             | 숫자 값 `3`                      |
| `1 + 2;`            | 표현식 문        | 덧셈 표현식             | 숫자 값 `3`                      |
| `value`             | 표현식           | 식별자 참조             | 바인딩에 저장된 값               |
| `value = 10`        | 표현식           | 할당 표현식             | 숫자 값 `10`                     |
| `value = 10;`       | 표현식 문        | 할당 표현식             | 숫자 값 `10`                     |
| `const value = 10;` | 선언             | 초기화 표현식 `10`      | 선언 전체를 값으로 사용하지 않음 |
| `if (value) run();` | 문               | 조건 표현식과 표현식 문 | 문 전체를 값으로 사용하지 않음   |
| `[1, 2]`            | 표현식           | 배열 리터럴             | 배열 객체값                      |
| `{ name: "Mars" }`  | 문맥에 따라 다름 | 객체 리터럴 또는 블록   | 문맥에 따라 다름                 |
