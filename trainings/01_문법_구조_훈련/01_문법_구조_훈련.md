# JavaScript 기본 코드 단위 구분 훈련 1

## 판정 범주

다음 용어 안에서 판정한다.

```txt
리터럴
식별자 참조
표현식
표현식 문
문
선언
값
문법 오류
```

## 답안 형식

```txt
전체:
내부:
값:
```

예:

```js
1 + 2;
```

```txt
전체: 표현식 문
내부: 덧셈 표현식
값: 숫자 값 3
```

```txt
값: 내부 표현식의 값은 숫자 값 `10`
```

## 문제 19

```txt

값: `count`의 값을 먼저 반환한 후 `1`을 증가시키므로, 본래 `count`에 바인딩된 값
```
