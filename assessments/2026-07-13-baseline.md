## 문제 1: 표현식의 평가 과정

### 코드

```js
function record(label, value) {
  console.log(label);

  return value;
}

const result = record("left", 10) + record("right", 20);

console.log("result: ", result);
```

### 실행 전 예상

#### 예상 출력

우선 평가(evaluate)가 시작되며 `record` 함수와 `result` 변수가 평가 된다. 그리고 `console.log("result: ", result);`가 실행되면서 `result`의 `record("left", 10)`가 먼저 실행되며 `record` 함수 내의 `console.log(label)`가 실행되면서 `left`가 출력되고, 이후 `record("right", 20)`가 실행되며 `right`가 출력된다. `record` 함수는 `value` 매개변수를 통해 `10`과 `20`이 반환되고, `result`는 `10`과 `20`을 더한 뒤 `console.log("result: ", result);`를 통해 `result: 30`이 출력된다. 즉, 출력 순서는 `"left"`, `"right"`, `30`이다.

#### 오류 발생 여부

#### 실행 순서

1. `record("left", 10)`
2. `record("right", 20)`
3. `console.log("result: ", result)`

#### 확신도

- 75

### 실제 결과

```bash
left
right
result: 30
```

### 예상과 실제의 차이

### 생긴 질문

자바스크립트는 평가 과정과 실행 과정을 거친다.

따라서 코드 평가 시 함수와 변수 선언문을 생성한다.

`record` 함수 선언문과 `result` 변수 선언문이 각각 평가되었을 것이다.

그렇다면 `console.log` 같은 것들은 어떻게 평가가 되는가? 아니면 그냥 실행 때 스택에 쌓이는 건가?

`console.log()`를 만약 변수에 할당하면 어떻게 되나?

값, 표현식, 선언문, 토큰 등에 대해서도 정확한 정의와 기준에 대해 알아볼 필요가 있을 것 같다.

평가는 어떻게 이루어지는가?
실행은 어떻게 이루어지는가? => 아마 실행 컨텍스트일텐데, 많은 부분을 잊었다. 다시 한 번 공부해 볼 필요가 있을 것.

## 문제 2: 값의 변화와 표현식 결과

```js
let value = 1;

const result = value++ + ++value;

console.log("value: ", value);
console.log("result: ", result);
```

### 예상

초기 상태:
value = 1

첫 번째 피연산자 평가 후:
표현식 값 = 원래 값인 1이 반환된 후 더해지므로 `result`는 1
value = 2

두 번째 피연산자 평가 후:
표현식 값 = value++로 더해진 값 2에서 ++value는 전위 연산자로, 값이 1 먼저 더해진 후 반환되므로 3으로 평가. 따라서 2 + 3이 되므로 5

덧셈 후:
result = 5

### 실제 결과

```bash
value: 3
result: 4
```

### 예상과 실제의 차이

`value`는 `1`이다. `result`에서 `value++`, `++value`가 사용될 때, 각각의 후위 연산자와 전위 연산자가 참조하는 값은 결국 `let value = 1;`의 `1`이다.

그렇다면 `const result = value++ + ++value;`에서, `value++`는 예상대로 `1`이 먼저 반환된 후 값이 증가하므로, `value: 2`, `result: 1`이 출력되는 것이 맞다.

하지만 나는 `value++ + ++value` 표현식에서, `++value`가 더하는 값 `value++`가 `2`일 것이라고 보았다.

`value++`는 `1`을 반환하고 `2`로 평가되는 것이 맞다.

따라서 `++value` 연산자가 실행되는 시점에서 평가되는 `value`의 값은 `2`가 맞으나, `value++`와 더할 때 `value++`의 값은 `1`인 것이다.

따라서 `2 + 3`이 아니라 `1 + 3`이 되는 것이다.

`console.log("value: ", value);`의 경우, `value++`와 `++value`로 인해 `1`에서 `2`로, `2`에서 `3`으로 더해졌으므로 `3`이 맞고, `console.log("result: ", result);`의 경우 앞서 말했듯 `1 + 3`이 맞다.

## 문제 3: 함수 인수 평가와 호출

```js
function createValue(label) {
  console.log("create: ", label);
  return label;
}

function combine(first, second) {
  console.log("combine: ", first, second);
}

combine(createValue("A"), createValue("B"));
```

### 예상

자바스크립트는 코드를 평가(evaluate)하고 실행(execution)한다.

그리고 평가 과정에서 함수나 변수의 선언문을 파악한다.

따라서 `createValue`와 `combine` 함수 선언문이 먼저 평가된다.

그리고 실행 과정에서 실행 컨텍스트가 생성되는데, 이때 `combine`이 호출 스택(call stack)에 들어서고, `combine`이 `createValue("A")`, `createValue("B")`이 순서대로 호출 스택에 들어설 것이다.

그렇다면

```txt
[createValue("B")]
[createValue("A")]
[combine(createValue("A"), createValue("B"))]
```

같은 형태가 될 것.

그럼 `createValue("A")`와 `createValue("B")`가 먼저 실행될 것이다.

라고 생각을 했는데, 그럼 중간에 있는 `createValue("A")`가 먼저 실행이 되어야 하는가?

그럴 것 같지 않다. 따라서 맨 위에 있는 `createValue("B")`가 먼저 실행되며 `create: B`가 먼저 출력될 것이다. 그리고 `B` 값이 반환될 것이다.

그 뒤 `createValue("A")`가 실행되며 `create: A`가 실행될 것이고 `A` 값이 반환될 것이다.

그리고 `combine`의 `console.log("combine: ", first, second)`이 실행되며 `combine: A B`가 출력될 것이다. 매개 변수로 받은 `first`는 `A`, `second`는 `B`이기 때문이다.

따라서 예상 출력 결과는

```bash
create: B
create: A
combine: A B
```

### 실제 결과

```bash
create: A
create: B
combine: A B
```

### 왜 이런 결과가 나왔을까

위에서 예상했듯이, 나는 호출 스택에 다음과 같이 쌓여 있을 것이라 예상했다.

```txt
[createValue("B")]
[createValue("A")]
[combine(createValue("A"), createValue("B"))]
```

하지만 실제 실행된 결과는 다음과 같다.

```bash
create: A
create: B
combine: A B
```

호출 스택은 (아마 내가 알기로) 맨 위에 올려진 함수가 먼저 실행된다.

실행 결과를 놓고 봤을 때 스택 구조 상 다음과 같이 되어 있을 것이다.

```txt
[createValue("A")]
[createValue("B")]
[combine(createValue("A"), createValue("B"))]
```

따라서 `create: A`가 먼저 출력되었을 것이다.

그렇다면 `createValue("B")`가 먼저 호출 스택에 들어갔다는 것인데, 그럼 `combine(createValue("A"), createValue("B"));`가 실행될 때, 두 번째 매개 변수인 `createValue("B")`가 먼저 놓인 것으로 보여진다.

그렇다면 호출 스택이 실제로 어떻게 동작하는지, 호출 스택이 실행(?)되는 시점은 언제인지, 매개 변수는 어떻게 평가되는지를 좀 더 자세히 알아보아야 할 것이다.
